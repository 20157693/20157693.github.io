## Selected Components

For my dashboard, I've chosen a few components from ScreenCraft to help organise the layout and make the website easy to navigate.

1. **Simple Header** (Components > Page Headers > Simple Header)
2. **Navigation Bar** to link to the home page and each phase of the portfolio.
3. **Simple Footer** (Components > Page Footers > Simple Footer)
4. **Vertical Card** (Components > Cards > Card (Vertical))
5. **Additional Cards** to display the remaining portfolio content.
6. **Copyright** to cite any resources used.

I'll use these components as a starting point and adapt them to suit my website.
